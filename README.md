# CLI Student Management System

A command-line **Student Management System** built with **TypeScript and Node.js**.

This project was developed during my time at **PIAIC (Presidential Initiative for Artificial Intelligence and Computing)** as part of my early programming and TypeScript learning.

## About

CLI Student Management System is a terminal-based application that simulates basic student management and academic account operations.

The project was created as a practical exercise for building an interactive CLI application while applying programming concepts to a more complete use case.

The application includes:

* Adding students
* Viewing the list of students
* Student login with a unique ID and password
* Adding balance to a student account
* Paying fees
* Enrolling in courses
* Viewing enrollment and account status
* Interactive command-line menus

## Installation & Usage

### Run with npx

The project was published as an npm package and can be run directly using:

```bash
npx adil-student-management
```

### Run from Source

Clone the repository and install its dependencies:

```bash
git clone https://github.com/SheikhXAdil/CLI-Student-Management-System.git
cd CLI-Student-Management-System
npm install
```

Then run the compiled JavaScript file:

```bash
node index.js
```
