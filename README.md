# CLI-Student-Management-System


This is a CLI-Student-Management-System built with nodejs and typescript which can impliment the following processes:


  - Adding a student and showing list of all students
  - Login portal of students with password and unique is
  - Adding balance to account, paying fee, enrolling in course, showing status



## Installation

run it with npm

```bash
  npx adil-student-management
```
